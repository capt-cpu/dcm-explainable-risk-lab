# DCM Explainable Risk Lab

面向科研与学术交流的纯静态风险预测演示工具。输入14项临床与影像指标后，页面在浏览器本地运行随机森林推理，并展示基于汇总参考患者的个体贡献近似解释。

## 使用

直接访问本仓库的 GitHub Pages 地址。无需安装、登录或上传数据。

## 隐私

- 所有输入仅在访问者的浏览器中处理。
- 页面不连接数据库，不保存或上传输入。
- 仓库不包含患者级原始数据。
- `model.json` 只包含脱敏后的森林结构和汇总预处理参数。

## 重要说明

- 预测结局为 `mJOA ≤ 12`。
- 页面中的 0.50 是演示阈值，正式临床阈值应在研究方案中预先锁定。
- 个体解释使用32次排列的参考患者近似，并不等同于论文中基于训练人群计算的标准 TreeSHAP。
- 本工具仅供科研与学术交流，不用于诊断或治疗决策。
